## Interfaces

All are doc deltas to `docs/CONTRACTS.md`, recorded on the subtask that introduces them. JSON is snake_case.

### Admin token (S1)

The usual JWT, plus a claim: HS256, `sub` = the admin's user id, `role` = `admin`, 24 hours. Storage Management and User Management read it as an admin. Updating doesn't look at the claim, so on `POST /run-poll` it is a user with no papers. Research Evaluation already answers it with `403`.

### `POST /auth/login` (S1)

Same endpoint, request and errors. The admin signs in with `{"email": "admin", "password": "12345679"}`. Register and login responses gain `user.role`:

```json
{"token": "eyJ...", "user": {"id": "uuid", "email": "admin", "role": "admin", "created_at": "2026-11-06T08:00:00Z"}}
```

`role` is `user` or `admin`.

### `GET /auth/admin/users` (S2, User Management)

Under `/auth` so the Vite proxy and Caddy already route it. Admin token only.

**`200`:** `{"users": [{"id": "uuid", "email": "a@b.c", "role": "user", "created_at": "..."}]}`, newest first, without the admin account.

Errors: `401` missing or bad token; `403` a user or service token; `404` dev mode off.

### `POST /admin/papers/{id}/snapshots` (S3, Storage Management, `/api/...` from the browser)

Admin token only, on any user's paper. Changes the paper's flags in its stored data: stores a new snapshot, a copy of the latest one with the given fields changed and `fetched_at` set to now. The next poll fetches the real values and compares them with this row, so setting a value to what it was before a real change makes that poll find the change.

**Request**, at least one field:

```json
{
  "is_retracted": false,
  "in_doaj": true,
  "cited_by_count": 0,
  "removed_crossref_update_types": ["retraction", "correction"]
}
```

| Field | Rules |
|---|---|
| `is_retracted`, `in_doaj` | boolean. Left out or null keeps the latest value |
| `cited_by_count` | integer of 0 or more. Left out or null keeps the latest value |
| `removed_crossref_update_types` | array of non-blank strings. Every entry of these types is left out of the new row's `crossref_updates` |

**`201`:** the new snapshot, in the shape `POST /internal/papers/{id}/snapshots` returns.

Errors: `400` a body that breaks the rules, no field given, or an id that isn't a UUID; `401`; `403` a user or service token; `404` `No paper <id>`, or dev mode off; `409` the paper has no snapshot yet (`Paper <id> has no snapshot yet; poll it once first`), or the latest snapshot's source for a given field isn't `ok`, since such a field is never compared.

### Admin reads (S4, Storage Management)

Admin token only, on any user's papers. Errors: `400` an id that isn't a UUID; `401`; `403` a user or service token; `404` `No paper <id>` (paper routes), or dev mode off.

| Call | `200` |
|---|---|
| `GET /admin/users/{ownerId}/papers` | `{"papers": [...]}`, newest first: each paper in the `GET /papers` shape plus `owner_id`, `latest_snapshot` (a snapshot row or null). An unknown owner gives `{"papers": []}` |
| `GET /admin/papers/{id}/snapshots` | `{"snapshots": [...]}`, the full history, oldest first, in the `GET /internal/papers/{id}/snapshots` shape |
| `GET /admin/papers/{id}/alerts` | the `GET /papers/{id}/alerts` body, dismissed alerts included |
| `GET /admin/papers/{id}/reports` | the `GET /papers/{id}/reports` body |
| `DELETE /admin/papers/{id}/history` | `204`. Deletes snapshots, alerts and reports, as `DELETE /dev/papers/{id}/history` does |

### `POST /admin/papers/{id}/fake-report?status=` (S8, Storage Management)

Admin token only, on any user's paper. No body. In one transaction, copies the one stored example (`storage/src/main/resources/dev/fake-report/`) onto the paper as new alerts, a new report grouping exactly those alerts, and that report's documents. The paper needs no DOI and no snapshot.

`status` is optional: `investigating`, `investigated` or `assessed` (the default).

| `status` | `investigated_at` | Evaluation fields |
|---|---|---|
| `investigating` | null | null |
| `investigated` | set | null |
| `assessed` | set | from the example, `evaluated_at` set |

**`201`:** the report, in the shape of one entry of `GET /papers/{id}/reports`.

Errors: `400` an unknown `status`, or an id that isn't a UUID; `401`; `403` a user or service token; `404` `No paper <id>`, or dev mode off.

### `GET /public/fake-report/{file}` (S8, Storage Management, `/api/...` from the browser)

No token, because a link opened in a new tab can't send one. Serves only the example's made-up document PDFs, `new-version.pdf` and `current-version.pdf`, as `application/pdf`. **`200`** with the file. `404` for any other name, or dev mode off.

### Example files in `storage/src/main/resources/dev/fake-report/` (S8)

`report.json`, `new-version.pdf`, `current-version.pdf`, `paper.pdf` and `draft.pdf`. All are made up. `paper.pdf` and `draft.pdf` are kept only as the record of what the prompts read, and are never served or stored on a paper.
